# zip

## 1. Definition

**`zip`** is an RxJS operator that combines multiple observables by pairing their emissions **in order** — emitting arrays when all observables have a corresponding value at the same index.

## 2. Why do we need it?

To synchronize multiple streams whose emissions must be paired element-by-element — especially useful in testing and deterministic scenarios.

## 3. Internal Working

1. Internally queues one item from each observable
2. When there’s one from every observable → emits them zipped
3. Stops when any input completes

## 4. Step-by-Step Execution

Example:
```javascript
const obs1 = from([1, 2, 3]);
const obs2 = from(['a', 'b', 'c']);
const obs3 = from([true, false]);

zip(obs1, obs2, obs1).subscribe(([x, str, bool]) => {
  console.log(x, str, bool); 
});

// Output:
// 1 'a' true
// 2 'b' false
```

Steps:
1. Queue one value from each stream
2. Once all have at least one item → emit zipped tuple
3. Next iteration pulls next item from each
4. Stops when shortest observable completes

## 5. Syntax

```javascript
zip(obs1, obs2, obs3).subscribe(...)
// OR in pipe
source$.pipe(zipWith(other$))
```

## 6. Examples (Easy → Advanced)

### Easy
```javascript
zip(
  from(['A', 'B']),
  from([1, 2])
).subscribe(([letter, num]) => {
  console.log(`${letter}${num}`); // A1, B2
});
```

### Medium
```typescript
// Pair timestamps with values
zip(
  this.timestamp$,
  this.dataValue$
).subscribe(([ts, val]) => {
  this.loggedData.push({ timestamp: ts, value: val });
});
```

### Advanced
```typescript
// Synchronize form validations
const nameControl$ = this.name.valueChanges.pipe(startWith(''));
const emailControl$ = this.email.valueChanges.pipe(startWith(''));

zip(nameControl$, emailControl$).subscribe(([nameValid, emailValid]) => {
  this.canSubmit = nameValid && emailValid;
});
```

## 8. Real-world Example

Angular unit test combining expected and actual sequences:
```typescript
it('should emit correct sequence', () => {
  const expectedValues = hot('--a--b--c');
  const actualValues = cold('---x---y---z').pipe(zipWith(someOther$));

  expect(actualValues).toEqual(expectedValues);
});
```

## 9. Angular Use Case

Aligning parallel streams (timestamped logs, paired API calls).

## 10. Common Mistakes

❌ Using `zip` where `combineLatest` would suffice  
❌ Assuming it works with infinite-length observables naively  

## 11. Edge Cases

1. **Mismatched lengths**
   ```javascript
   zip(from([1,2,3]), from(['a'])) 
   // Only emits once before shorter completes
   ```

2. **Infinite streams**
   ```javascript
   zip(timer(0,1000), interval(0,500)) // Will keep producing forever
   ```

## 12. Performance Considerations

Lightweight unless dealing with very large synchronized datasets.

## 13. Time & Space Complexity

O(min(N,M)) where N/M are input lengths.
