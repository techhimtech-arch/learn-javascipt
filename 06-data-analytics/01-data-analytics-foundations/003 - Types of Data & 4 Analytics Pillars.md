# 💡 Data Key 2 Main Types (Structured vs Unstructured)

Data Analytics shuru karne se pehle pata hona chahiye ki Data dikhta kaisa hai!

```
                            Data Types
                                │
          ┌─────────────────────┴─────────────────────┐
          ▼                                           ▼
   Structured Data                            Unstructured Data
(Excel Rows, SQL Tables)                     (Images, Audio, PDF, Tweets)
```

### 1. Structured Data (Table-Like Format)
- Jo data Excel sheet ya SQL database table me Perfectly Rows aur Columns me organized hota hai.
- *Examples:* Customer ID, Name, Age, Salary, Order Amount.

### 2. Unstructured Data (No Fixed Format)
- Videos, Customer voice calls, WhatsApp chat logs, PDFs, Images.
- *Note:* Data Analysts 80% time **Structured Data** par kaam karte hain.

# 🔢 Quantitative vs Qualitative Data

```
                      Structured Data Breakdown
                                 │
         ┌───────────────────────┴───────────────────────┐
         ▼                                               ▼
 Quantitative (Numerical / Numbers)               Qualitative (Categorical / Text)
- Discrete: Countable (e.g. 5 orders)            - Nominal: Names, Gender, Cities
- Continuous: Measurable (e.g. 72.5 kg)           - Ordinal: Ratings (Low/Med/High)
```

| Type | Sub-type | Example |
|---|---|---|
| **Quantitative** (Numbers) | **Discrete** | Number of items bought (1, 2, 3...) |
| | **Continuous** | Temperature (36.6 °C), Price ($19.99) |
| **Qualitative** (Text/Category) | **Nominal** | Eye color (Blue, Brown), Payment Method (UPI, Card) |
| | **Ordinal** | Star Rating (1 Star, 2 Star... 5 Star), Shirt Size (S, M, L, XL) |

# 🏛️ The 4 Pillars of Data Analytics

Analytics me 4 tarah ke questions poochhe jaate hain:

```
        High Value ┌──────────────────────────────────────────────── Prescriptive Analytics
                   │                                                  (What should we do?)
                   │                                Predictive Analytics
                   │                                (What will happen?)
                   │                  Diagnostic Analytics
                   │                  (Why did it happen?)
         Low Value └─ Descriptive Analytics
                      (What happened?)
                      ─────────────────────────────────────────────────────►
                      Past / Present                        Future Outlook
```

### 1. Descriptive Analytics (What happened?)
- **Puraane data ka summary dikhana.**
- *Example:* "Pichle mahine Flipkart ne ₹100 Crore ki Sales ki."

### 2. Diagnostic Analytics (Why did it happen?)
- **Reason / Root Cause dhoondna.**
- *Example:* "Sales 20% kyu badi? Kyunki Diwali sale chal rahi thi aur electronics par 40% discount tha."

### 3. Predictive Analytics (What will happen in the future?)
- **Past patterns se future forecast karna.**
- *Example:* "Next month Aagami Festival season me demand 30% badhne ki sambhavna hai."

### 4. Prescriptive Analytics (What action should we take?)
- **Best solution recommend karna.**
- *Example:* "Inventory me 5,000 extra smartphones stock me rakho taaki out-of-stock na ho."

# 🚀 2-Minute Revision Card

- **Data Formats:** Structured (Tables/SQL) vs Unstructured (Audio/Video/Images).
- **Quantitative Data:** Numbers (Discrete = count, Continuous = measurement).
- **Qualitative Data:** Categories (Nominal = no order, Ordinal = with ranking).
- **4 Analytics Pillars:**
  1. *Descriptive:* What happened?
  2. *Diagnostic:* Why did it happen?
  3. *Predictive:* What will happen?
  4. *Prescriptive:* What should we do next?
