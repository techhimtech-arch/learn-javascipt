# SVG

## 1. Definition

**Scalable Vector Graphics (SVG)** is an XML-based markup language for describing two-dimensional vector graphics.

Unlike raster images (PNG/JPG), SVG graphics scale infinitely without quality loss.

## 2. Why do we need it?

- Resolution-independent graphics
- Stylistable with CSS
- Accessible via DOM
- Editable with JavaScript

## 3. Internal Working

Browser parses SVG markup similarly to HTML, constructing vector paths/shapes into a renderable format.

SVG scales mathematically rather than pixel-by-pixel.

## 4. Step-by-Step Execution

Example:
```html
<svg width="100" height="100">
  <circle cx="50" cy="50" r="40" fill="blue" />
</svg>
```

Steps:
1. Parse `<svg>` element
2. Create circle shape with center/radius
3. Apply fill color
4. Render vector geometry to pixels

## 5. Syntax

```xml
<svg viewBox="0 0 100 100">
  <rect x="10" y="10" width="80" height="80" rx="10"/>
  <circle cx="50" cy="50" r="30" />
  <line x1="0" y1="0" x2="100" y2="100" stroke="black"/>
  <path d="M10 10 L90 90" />
  <text x="50" y="50">Label</text>
</svg>
```

## 6. Examples (Easy → Advanced)

### Easy
```html
<svg>
  <rect width="100" height="50" fill="tomato" />
</svg>
```

### Medium
```html
<svg>
  <circle cx="50" cy="50" r="40" stroke="black" stroke-width="3" fill="yellow" />
</svg>
```

### Advanced
```html
<svg>
  <defs>
    <linearGradient id="grad1" x1="0%" y1="0%" x2="100%" y2="0%">
      <stop offset="0%" style="stop-color:rgb(255,255,0);stop-opacity:1" />
      <stop offset="100%" style="stop-color:rgb(255,0,0);stop-opacity:1" />
    </linearGradient>
  </defs>
  <rect width="100%" height="100%" fill="url(#grad1)" />
</svg>
```
