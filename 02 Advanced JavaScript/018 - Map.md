# Map

## 1. Definition

A **Map** is a collection of key/value pairs where keys can be **any value** (not just strings/Symbols like plain objects).

Maintains insertion order and supports efficient additions/deletions.

## 2. Why do we need it?

- Better performance than plain objects for frequent additions/removals
- Keys of any type supported
- Size tracking available

## 3. Internal Working

Internally stored as hash table or tree-based structure depending on engine — guarantees O(1)/O(log n) operations.

## 4. Step-by-Step Execution

```javascript
const m = new Map();
m.set("key", 1);
m.get("key"); // 1
m.delete("key");
m.has("key"); // false
```

## 5. Syntax

```javascript
const map = new Map([[key, value], ...]);
map.set(k, v);
map.get(k);
map.has(k);
map.delete(k);
map.clear();
```

## 6. Examples (Easy → Advanced)

### Easy
```javascript
const userRoles = new Map([
  ["admin", "Full Access"],
  ["editor", "Limited Access"]
]);
console.log(userRoles.get("admin"));
```

### Medium
```javascript
const groupedByCategory = items.reduce((acc, item) => {
  const group = acc.get(item.category) || [];
  group.push(item);
  acc.set(item.category, group);
  return acc;
}, new Map());
```

### Advanced
```javascript
const cache = new Map();
function memoizedFetch(url) {
  if (cache.has(url)) return Promise.resolve(cache.get(url));
  return fetch(url).then(res => {
    const json = res.json();
    cache.set(url, json);
    return json;
  });
}
```
