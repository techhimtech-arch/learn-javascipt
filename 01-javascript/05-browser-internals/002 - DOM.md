# DOM

## 1. Definition

The **Document Object Model (DOM)** is a programming interface representing structured documents as treelike node structures.

## 2. Why do we need it?

To programmatically access and manipulate HTML/XML content dynamically.

## 3. Internal Working

Each tag becomes a node in tree structure:
- Root: document
- Children: elements, text nodes, comments

Methods like `getElementById`, `querySelector` traverse the tree.

## 4. Step-by-Step Execution

Accessing element:
1. Call `document.getElementById("myDiv")`
2. Browser searches DOM for matching ID
3. Returns reference to Element node
4. Modify `.textContent`, `.innerHTML`, attributes, styles

## 5. Syntax

```javascript
document.getElementById(id)
document.querySelector(selector)
element.setAttribute(name, value)
element.appendChild(child)
```

## 6. Examples (Easy → Advanced)

### Easy
```javascript
document.querySelector("#title").textContent = "New Title";
```

### Medium
```javascript
const ul = document.querySelector("ul");
const li = document.createElement("li");
li.textContent = "Item";
ul.appendChild(li);
```

### Advanced
```javascript
document.addEventListener("click", (event) => {
  event.target.closest('.card')?.classList.toggle('open');
});
```

## 10. Common Mistakes

❌ Direct DOM mutation bypassing Angular  
❌ Frequent queries causing performance hit

## 11. Edge Cases

1. **Event delegation**
   ```javascript
   document.body.addEventListener("click", handler);
   ```

2. **MutationObserver**
   ```javascript
   new MutationObserver(callback).observe(node, config);
   ```

## 12. Performance Considerations

Minimize repeated DOM access — cache references.

## 13. Time & Space Complexity

Query: O(n) worst-case  
Traversal: proportional to subtree size

## 18. Revision Notes

- Angular abstracts with Renderer2

## 🔍 Quick Recap
- DOM = tree of nodes (elements, text, comments)
- Access via selectors/query methods
- Direct updates trigger reflows if geometry changes
- Angular uses Renderer2 for safe DOM manipulation

## 📝 Summary
The DOM represents HTML as a live tree. JavaScript interacts through methods like `querySelector`, `addEventListener`. Efficient use requires minimizing layout thrashing and caching element references.
