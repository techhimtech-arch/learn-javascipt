# Set

## 1. Definition

A **Set** is a collection of **unique values** — primitives or object references — with guaranteed uniqueness and insertion-order iteration.

## 2. Why do we need it?

Efficiently remove duplicates and perform membership tests without manual checks.

## 3. Internal Working

Backed by hash table-like structure storing distinct entries. Insertion triggers deduplication check.

## 4. Step-by-Step Execution

```javascript
const s = new Set();
s.add(1);
s.add(2);
s.add(1); // ignored
s.has(1); // true
```

## 5. Syntax

```javascript
const set = new Set([iterable]);
set.add(value);
set.has(value);
set.delete(value);
set.clear();
```

## 6. Examples (Easy → Advanced)

### Easy
```javascript
const unique = [...new Set([1, 2, 2, 3, 3, 3])];
console.log(unique); // [1, 2, 3]
```

### Medium
```javascript
const visited = new Set();
function dfs(node) {
  if (visited.has(node)) return;
  visited.add(node);
  node.neighbors.forEach(dfs);
}
```

### Advanced
```javascript
class EventEmitter {
  listeners = new Set();
  subscribe(listener) {
    this.listeners.add(listener);
    return () => this.listeners.delete(listener);
  }
  emit(...args) {
    this.listeners.forEach(l => l(...args));
  }
}
```
